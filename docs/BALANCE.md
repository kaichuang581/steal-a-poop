# Balance simulation

Generated by `scripts/simulate.ts`: 200 games per row, every seat played by the engine's bot logic (seat 0 included, so no human skill is modelled). Seeds are fixed, so the run is repeatable, and both runs use the same 200 seeds per row.

The only difference between the two runs is the turn setting, so rows compare directly.
