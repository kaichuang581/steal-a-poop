# Reference sheets for the diorama props

Brian adds these (docs/diorama/PLAN.md, 5.1): for every prop, `<id>-34.png` (three-quarter view), `<id>-front.png`,
`<id>-side.png` and `<id>-top.png` (orthographic), on the plain off-white background, made with the prompt in 5.1.
If a view disagrees with the three-quarter view, the three-quarter view wins. Brian's farm and prop pictures that the
palette was sampled from go here too.

`tools/propMatch.mjs` compares every recipe's front, side and top renders with these pictures. Nothing here is ever
edited to make a prop pass.
