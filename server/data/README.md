# Data

`blocklist-en.txt` is the English list from "List of Dirty, Naughty, Obscene, and Otherwise Bad Words"
(https://github.com/LDNOOBW/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words), licensed
Creative Commons Attribution 4.0 International. Fetched unmodified. Many entries are ordinary words in
other contexts, so a match is a reason to review, not proof of abuse.
